# tedwardd/homebrew-tap

Homebrew tap for my tools.

## Install

```sh
brew install --cask tedwardd/tap/claude-monitor
```

Or tap it first if you prefer:

```sh
brew tap tedwardd/tap
brew install --cask claude-monitor
```

## Contents

| Cask | Source | Description |
|---|---|---|
| `claude-monitor` | [tmux-claude-monitor](https://github.com/tedwardd/tmux-claude-monitor) | tmux status bar daemon that displays Claude Pro quota usage |

Files under `Casks/` are generated by GoReleaser when the upstream project cuts
a release. Hand edits there get overwritten on the next release.
